# The Hidden World — Veo 3 Production Kit

A complete, paste-ready kit to produce one cinematic vertical YouTube Short
(~60 sec, 9:16) in realistic 3D animation with a professional male narrator,
emotional score, and suspenseful SFX.

> **Important:** These files are the *script and prompts*. You generate the
> actual clips in **Veo 3** (Google Flow / Gemini) using your own account and
> credits, then stitch them. This kit is what makes the result look like your
> reference — follow it in order.

## Files in this folder
1. `01-shot-list.md` — the 8-scene breakdown, timing, and story beats.
2. `02-veo3-prompts.md` — one copy-paste prompt per scene (the core of the kit).
3. `03-voiceover-script.md` — the narrator lines, timed to the cuts, + TTS setup.
4. `04-music-sfx-and-assembly.md` — audio choices and how to stitch + export.

## The workflow (start to finish)

**Step 1 — Generate the 8 clips in Veo 3**
- Open Veo 3 in Google Flow (labs.google/fx) or the Gemini app.
- Set output to **9:16 vertical**, 8-second clips.
- Paste the **CHARACTER BLOCK** (top of file 02) + each scene prompt, one at a time.
- Generate 2–3 variations per scene and keep the best. Expect to re-roll some.

**Step 2 — Record / generate the voiceover**
- Use file 03. Either record your own voice, or use a TTS tool (ElevenLabs
  recommended — see file 03 for exact voice + settings).

**Step 3 — Assemble**
- Drop the 8 clips in order into CapCut (free) or Premiere.
- Lay the narrator track on top; add the music bed and the 3 SFX stingers.
- Export 1080×1920, H.264, 30fps. Details in file 04.

**Total expect:** ~45–90 min of hands-on work, most of it waiting on Veo renders.

## Two decisions baked in (change if you want)
- **Audio from Veo:** prompts ask Veo for *ambient + SFX only, no speech/music*,
  so your narrator and score sit cleanly on top. If you'd rather use Veo's own
  audio, delete the "no dialogue, no music" line from each prompt.
- **Character name:** the young man is called **Kai** in the narration. Swap the
  name freely — it only appears in file 03.
