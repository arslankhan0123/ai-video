# 02 — Veo 3 Prompts (the core of the kit)

## How to use
1. In Veo 3, set **aspect ratio 9:16** and clip length **8s**.
2. For **each** scene, paste the **CHARACTER BLOCK** first, then the scene's
   prompt below it, as one prompt.
3. Generate 2–3 takes, keep the best. Re-roll scenes where Kai's face drifts.
4. Keep the "no spoken dialogue, no music" line so your narrator + score layer
   cleanly in post. (Remove it if you want Veo's own audio instead.)

---

## CHARACTER BLOCK — paste at the top of every scene prompt

> **Character (keep identical in every shot):** Kai — a lean young man, early
> 20s, warm tan skin, short tousled black hair, dark expressive eyes, faint
> stubble. Wears a weathered charcoal-grey hooded jacket over a dark shirt,
> fitted trousers, worn leather boots. Athletic, grounded posture.
> **Style:** photorealistic cinematic 3D animation, rendered like a high-end
> animated feature, ultra-detailed textures, volumetric lighting, shallow depth
> of field, film grain, 9:16 vertical.

## Re-roll tips if a clip isn't right
- **Face/outfit drifts:** re-paste the CHARACTER BLOCK verbatim; add "same face
  as before, consistent character design."
- **Unwanted text on screen:** add "absolutely no text, no captions, no logos."
- **Too fast / too busy:** add "single slow continuous motion, one action only."
- **Wrong aspect:** confirm 9:16 is set in the Veo UI, not just the prompt.
